## 🎯 一、项目定位与目标

### **1.1 项目愿景**

打造**个人专属 IP 孵化平台**，让用户可以：
1. 创建和管理个人 IP 资产
2. 训练专属角色 LoRA 模型
3. 生成高质量、高一致性的 IP 图片

---

### **1.2 核心价值**

```
传统 AI 绘图工具                    IP Creator
├─ 通用模型                        ├─ 个人专属 LoRA
├─ 角色不一致                      ├─ 90%+ 角色一致性
├─ 无法控制细节                    ├─ 精确控制服装/表情/动作
└─ 重复训练成本高                  └─ 一次训练，永久使用
```

## 📊 三、数据模型设计

### **3.1 核心表结构**

```
ip_assets (IP 资产基础信息)
  │
  ├─ reference_images (JSON) → 用于 IP-Adapter
  │
  ├─ ip_multi_views (1:N) → 标准三视图
  │   └─ 字段：view_type, image_path, source
  │
  └─ ip_feature_library (1:N) → 特征库 ⭐
      │
      ├─ feature_type: outfit/expression/pose/...
      ├─ feature_name: casual_wear/happy/standing
      ├─ trigger_phrase: wearing casual clothes
      │
      └─ ip_feature_images (1:N) → 特征图片
          └─ 字段：angle, image_path, source

training_datasets (训练数据集)
  │
  ├─ ip_asset_id → 关联 IP
  ├─ name, description
  │
  └─ dataset_images (1:N) → 数据集图片
      ├─ file_path
      ├─ caption → "xiao_huli, front view, ..."
      ├─ angle, expression, pose
      └─ is_augmented, parent_image_id

lora_models (LoRA 模型)
  ├─ ip_asset_id
  ├─ dataset_id
  ├─ model_path
  ├─ quality_score
  └─ training_checkpoints (1:N)
```
