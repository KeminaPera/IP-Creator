## 1. 项目背景

### 1.1 现状分析

**当前三视图生成流程存在以下问题**：

| 问题类别 | 具体表现 | 影响程度 |
|---------|---------|---------|
| **交互模式** | 一次性生成三视图，无法单独控制 | ⭐⭐⭐⭐⭐ |
| **参数配置** | 全局统一参数，缺乏灵活性 | ⭐⭐⭐⭐ |
| **参考图选择** | 自动使用所有参考图，无法针对视图选择 | ⭐⭐⭐⭐⭐ |
| **进度监控** | 前端轮询（每2秒），延迟高、服务器压力大 | ⭐⭐⭐⭐ |
| **透明度** | Prompt不可见，生成过程黑盒 | ⭐⭐⭐ |
| **调试能力** | 无法控制Seed，无法复现结果 | ⭐⭐⭐⭐ |
| **错误处理** | 一个视图失败影响全部 | ⭐⭐⭐ |

### 1.2 用户痛点

1. **正面照不像**: 参考图预处理裁剪关键特征，IP-Adapter权重过高
2. **角度混乱**: 无法为不同视图选择最佳参考图
3. **无法复现**: 随机Seed导致每次结果不同
4. **调试困难**: 看不到实际使用的Prompt和参数
5. **等待时间长**: 轮询延迟2-3秒，进度更新不流畅

### 1.3 改造目标

```
从"批量粗放生成"转变为"精细可控生成 + 统一管理"

✅ 每个视图独立配置
✅ 每个视图专注自己的参考图  
✅ 每个视图独立生成和重试
✅ 实时进度推送（WebSocket）
✅ 完整的参数控制和透明度
✅ 提高相似度和可控性
✅ 生成结果自动保存到IP资产多视图库 ⭐ 新增
✅ AI生成参数完整落库，支持追溯和复现 ⭐ 新增
✅ 统一路径管理（复制到resources目录）⭐ 新增
```

## 3. 核心设计理念

### 3.1 架构原则

```
┌─────────────────────────────────────────────────────┐
│                 设计原则金字塔                        │
├─────────────────────────────────────────────────────┤
│                  用户体验优先                         │
│               ┌───────────────┐                     │
│              │  状态一致性    │                      │
│             │  ┌───────────┐  │                     │
│            │  │ 单一数据源 │  │                     │
│           │  │ ┌─────────┐ │ │                     │
│          │  │ │WebSocket│ │ │                     │
│         │  │ │实时推送  │ │ │                     │
│        └──┴─┴─┴─────────┴─┴─┘                     │
└─────────────────────────────────────────────────────┘
```

1. **单一数据源**: 所有状态集中在Pinia Store，避免分散
2. **状态一致性**: WebSocket、UI、后端状态保持同步
3. **WebSocket优先**: 实时推送替代轮询，降级策略兜底
4. **用户体验优先**: 进度准确、反馈即时、操作直观

### 3.2 设计模式

| 模式 | 应用场景 | 优势 |
|------|---------|------|
| **单一WebSocket连接池** | 多任务监听 | 减少连接数，统一管理 |
| **发布-订阅模式** | 进度推送 | 解耦Celery和前端 |
| **状态机模式** | 视图状态管理 | 清晰的状态转换 |
| **策略模式** | 批量生成 | 灵活的生成策略 |
| **降级模式** | 错误处理 | WebSocket→轮询→手动 |

### 3.3 关键决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 状态管理 | Pinia Store | Vue 3官方推荐，TypeScript友好 |
| 实时通信 | WebSocket + Redis Pub/Sub | 已基础设施，低延迟 |
| 进度计算 | 基于时间预估 | 比基于步骤更准确 |
| 批量生成 | 默认依次，可选智能 | 避免GPU OOM |
| 并发控制 | 前端+后端双重限制 | 防止资源耗尽 |

```javascript
 * WebSocket实时生成进度推送Composable
 * 
 * 特性:
 * - 自动连接/重连
 * - 消息路由（按task_id）
 * - 降级策略（WebSocket失败→HTTP轮询）
 * - 资源自动清理
 */
import { ref, onUnmounted } from 'vue'
import { ElMessage } from 'element-plus'

export function useGenerationWebSocket(options = {}) {
  const {
    autoConnect = false,
    reconnectInterval = 3000,
    maxReconnectAttempts = 3
  } = options

  // 响应式状态
  const isConnected = ref(false)
  const progress = ref(0)
  const status = ref('pending')
  const message = ref('')
  const result = ref(null)
  const error = ref(null)
  const reconnectAttempts = ref(0)

  // 内部状态
  let ws = null
  let reconnectTimer = null
  let pollingTimer = null
  const handlers = new Map() // {taskId: handler}

  /**
   * 连接WebSocket
   */
  const connect = () => {
    if (ws && ws.readyState === WebSocket.OPEN) {
      return
    }

    status.value = 'connecting'
    
    const wsUrl = getWsUrl()
    ws = new WebSocket(wsUrl)

    ws.onopen = () => {
      isConnected.value = true
      reconnectAttempts.value = 0
      status.value = 'connected'
    }

    ws.onmessage = (event) => {
      const data = JSON.parse(event.data)
      handleMessage(data)
    }

    ws.onerror = () => {
      error.value = 'WebSocket connection error'
    }

    ws.onclose = () => {
      isConnected.value = false
      
      // 任务完成后不重连
      if (status.value === 'completed' || status.value === 'failed') {
        return
      }
      
      // 尝试重连或降级
      if (reconnectAttempts.value < maxReconnectAttempts) {
        scheduleReconnect()
      } else {
        fallbackToPolling()
      }
    }
  }

  /**
   * 订阅任务进度
   */
  const subscribe = (taskId, handler) => {
    handlers.set(taskId, handler)
  }

  /**
   * 取消订阅
   */
  const unsubscribe = (taskId) => {
    handlers.delete(taskId)
  }

  /**
   * 处理消息
   */
  const handleMessage = (data) => {
    if (data.type === 'generation_progress' || 
        data.type === 'generation_complete' ||
        data.type === 'generation_failed') {
      
      const taskId = data.task_id
      const handler = handlers.get(taskId)
      
      if (handler) {
        handler(data)
      }

      // 更新全局状态（如果有活跃任务）
      if (taskId === activeTaskId.value) {
        progress.value = data.data.progress
        status.value = data.data.status
        message.value = data.data.message
      }
    }
  }

  /**
   * 降级到HTTP轮询
   */
  const fallbackToPolling = async () => {
    ElMessage.warning('WebSocket连接失败，切换到轮询模式')
    
    pollingTimer = setInterval(async () => {
      const taskId = activeTaskId.value
      if (!taskId) return

      try {
        const response = await fetchTaskStatus(taskId)
        const handler = handlers.get(taskId)
        if (handler) {
          handler({
            type: 'generation_progress',
            task_id: taskId,
            data: response
          })
        }

        if (response.status === 'completed' || response.status === 'failed') {
          clearInterval(pollingTimer)
        }
      } catch (err) {
        console.error('Polling error:', err)
      }
    }, 3000)
  }

  /**
   * 断开连接
   */
  const disconnect = () => {
    if (reconnectTimer) {
      clearTimeout(reconnectTimer)
    }
    if (pollingTimer) {
      clearInterval(pollingTimer)
    }
    if (ws) {
      ws.close()
      ws = null
    }
    handlers.clear()
  }

  // 自动连接
  if (autoConnect) {
    connect()
  }

  // 组件卸载时清理
  onUnmounted(() => {
    disconnect()
  })

  return {
    isConnected,
    progress,
    status,
    message,
    result,
    error,
    connect,
    disconnect,
    subscribe,
    unsubscribe
  }
}
```

```python
class ConnectionManager:
    """WebSocket连接管理器（支持训练和生成任务）"""
    
    def __init__(self):
        # 训练连接: {lora_id: [websocket1, ...]}
        self.training_connections: Dict[int, List[WebSocket]] = {}
        
        # 生成连接: {task_id: [websocket1, ...]}
        self.generation_connections: Dict[str, List[WebSocket]] = {}
    
    async def connect_generation(self, websocket: WebSocket, task_id: str):
        """接受生成任务的WebSocket连接"""
        await websocket.accept()
        
        if task_id not in self.generation_connections:
            self.generation_connections[task_id] = []
        
        self.generation_connections[task_id].append(websocket)
        logger.info(f"✅ WebSocket connected for generation {task_id}")
    
    def disconnect_generation(self, websocket: WebSocket, task_id: str):
        """断开生成任务的WebSocket连接"""
        if task_id in self.generation_connections:
            if websocket in self.generation_connections[task_id]:
                self.generation_connections[task_id].remove(websocket)
            
            if not self.generation_connections[task_id]:
                del self.generation_connections[task_id]
    
    async def send_generation_progress(self, task_id: str, data: dict):
        """发送生成进度消息"""
        message = json.dumps({
            "type": "generation_progress",
            "task_id": task_id,
            "data": data
        })
        
        await self._send_to_generation(task_id, message)
    
    async def send_generation_complete(self, task_id: str, data: dict):
        """发送生成完成消息"""
        message = json.dumps({
            "type": "generation_complete",
            "task_id": task_id,
            "data": data
        })
        
        await self._send_to_generation(task_id, message)
    
    async def send_generation_failed(self, task_id: str, error: str):
        """发送生成失败消息"""
        message = json.dumps({
            "type": "generation_failed",
            "task_id": task_id,
            "data": {"error": error}
        })
        
        await self._send_to_generation(task_id, message)
    
    async def _send_to_generation(self, task_id: str, message: str):
        """发送消息到指定任务的所有连接"""
        if task_id not in self.generation_connections:
            return
        
        disconnected = []
        
        for connection in self.generation_connections[task_id]:
            try:
                await connection.send_text(message)
            except Exception as e:
                disconnected.append(connection)
        
        # 清理断开的连接
        for conn in disconnected:
            self.disconnect_generation(conn, task_id)
```

```python
        "lora_path": ip_asset.lora_model_id if request.use_lora else None,
        "lora_weight": request.lora_weight if request.use_lora else 0.0,
        "use_ip_adapter": request.generation_mode == 'ip_adapter',
        "reference_images": [request.reference_image] if request.reference_image else [],
        "negative_prompt": build_negative_prompt(ip_asset),
        "ip_adapter_scale": request.ip_adapter_scale,
        "width": request.width,
        "height": request.height,
        "steps": request.steps,
        "cfg_scale": request.cfg_scale,
        "seed": request.seed if request.seed != -1 else None,
    }
    
    # 6. 创建Celery任务
    task = generate_image_task.apply_async(
        args=[prompt, ip_id],
        kwargs=task_kwargs,
        queue="image_generation"
    )
    
    # 7. 创建任务记录
    task_record = TaskRecord(
        task_id=task.id,
        task_type="image_generation",
        status="pending",
        progress=0,
        created_by=current_user.id,
    )
    db.add(task_record)
    await db.commit()
    
    # 8. 返回task_id
    return success_response(
        data={
            "task_id": task.id,
            "view_type": view_type,
            "status": "pending",
        },
        message="视图生成任务已创建"
    )
```

### 10.2 路径统一管理方案

#### 10.2.1 为什么需要复制？

**问题背景**:
- ImageUploader组件硬编码上传到 `data/resources/` 目录
- Celery生成图片保存到 `data/videos/images/` 目录
- 多视图管理期望统一的路径格式

**解决方案**: 生成完成后，复制图片到resources目录

```python
def copy_generated_to_resources(
    image_path: str,           # data/videos/images/ip_1/xxx.png
    ip_asset_id: int,
    view_type: str
) -> str:
    """
    复制生成图片到resources目录
    
    Returns:
        复制后的路径: data/resources/{year}/{month}/{day}/{uuid}_{name}.png
    """
    import shutil
    import uuid
    from pathlib import Path
    from datetime import datetime
    
    try:
        original_path = Path(image_path)
        if not original_path.exists():
            raise FileNotFoundError(f"Generated image not found: {image_path}")
        
        # 1. 生成目标路径（符合resources规范）
        now = datetime.now()
        date_folder = Path(f"data/resources/{now.year}/{now.month:02d}/{now.day:02d}")
        date_folder.mkdir(parents=True, exist_ok=True)
        
        # 使用UUID + 原文件名
        file_uuid = uuid.uuid4().hex[:12]
        file_name = f"{file_uuid}_{original_path.name}"
        target_path = date_folder / file_name
        
        # 2. 复制图片
        shutil.copy2(original_path, target_path)
        logger.info(f"✅ Copied generated image to resources: {target_path}")
        
        # 3. 复制缩略图（如果存在）
        thumb_path = original_path.parent / 'thumbnails' / f"thumb_{original_path.name}"
        if thumb_path.exists():
            thumb_target = date_folder / 'thumbnails' / f"thumb_{file_name}"
            thumb_target.parent.mkdir(exist_ok=True)
            shutil.copy2(thumb_path, thumb_target)
            logger.info(f"✅ Copied thumbnail to resources: {thumb_target}")
        
        return str(target_path)
        
    except Exception as e:
        logger.error(f"Failed to copy image to resources: {e}")
        raise
```

```python
def save_to_multi_view(
    ip_asset_id: int,
    view_type: str,
    image_path: str,
    source: str,
    generation_params: dict,
    quality_score: float = None,
    is_primary: bool = None
):
    """
    保存生成结果到多视图库
    
    Args:
        ip_asset_id: IP资产ID
        view_type: 视图类型 (front/side/back)
        image_path: 图片路径（resources目录）
        source: 来源 ('generated' 或 'uploaded')
        generation_params: 完整生成参数
        quality_score: 一致性评分 (0-100)
        is_primary: 是否主视图 (None=自动判断)
    """
    from app.config.database import get_sync_session
    from app.models.ip_multi_view import IPMultiView
    from sqlalchemy import select
    import logging
    
    logger = logging.getLogger(__name__)
    
    try:
        with get_sync_session() as session:
            # 1. 判断是否为主视图
            if is_primary is None:
                # 查询是否已有该类型的视图
                existing = session.execute(
                    select(IPMultiView).where(
                        IPMultiView.ip_asset_id == ip_asset_id,
                        IPMultiView.view_type == view_type
                    )
                ).scalar_one_or_none()
                
                is_primary = (existing is None)  # 第一个自动设为主视图
            
            # 2. 创建多视图记录
            multi_view = IPMultiView(
                ip_asset_id=ip_asset_id,
                view_type=view_type,
                image_path=image_path,
                source=source,
                generation_params=generation_params,
                quality_score=quality_score,
                is_primary=is_primary,
            )
            
            session.add(multi_view)
            session.commit()
            
            logger.info(
                f"✅ Multi-view created: "
                f"IP={ip_asset_id}, type={view_type}, "
                f"primary={is_primary}, score={quality_score}"
            )
            
            return multi_view
            
    except Exception as e:
        logger.error(f"Failed to save to multi-view: {e}")
```

### 10.1 Pinia Store设计

```javascript
// stores/generation.js

import { defineStore } from 'pinia'
import { generateViewAPI } from '@/api/generation'
import { useGenerationWebSocket } from '@/composables/useGenerationWebSocket'

export const useGenerationStore = defineStore('generation', {
  state: () => ({
    // IP资产信息
    ipAsset: null,
    
    // 当前活动页签
    activeTab: 'front',
    
    // 批量生成策略
    batchStrategy: 'sequential', // sequential | smart | parallel
    
    // 三个视图的状态（单一数据源）
    views: {
      front: {
        taskId: null,
        status: 'pending', // pending | creating | connecting | generating | success | failed
        progress: 0,
        result: null,
        error: null,
        params: getDefaultParams()
      },
      side: { /* 相同结构 */ },
      back: { /* 相同结构 */ }
    },
    
    // WebSocket实例（复用连接）
    wsInstance: null,
  }),
  
  getters: {
    // 是否可以生成
    canGenerate: (state) => (viewKey) => {
      const view = state.views[viewKey]
      if (view.status === 'generating') return false
      
      if (view.params.generation_mode === 'ip_adapter' && 
          !view.params.reference_image) {
        return false
      }
      
      return true
    },
    
    // 批量生成状态
    batchStatus: (state) => {
      const views = Object.values(state.views)
      const completed = views.filter(v => v.status === 'success').length
      const failed = views.filter(v => v.status === 'failed').length
      const generating = views.filter(v => v.status === 'generating').length
      
      return {
        total: 3,
        completed,
        failed,
        generating,
        allSuccess: completed === 3,
        hasFailed: failed > 0,
      }
    },
  },
  
  actions: {
    /**
     * 生成单个视图
     */
    async generateView(viewKey) {
      const view = this.views[viewKey]
      
      // 1. 验证参数
      if (view.params.generation_mode === 'ip_adapter' && 
          !view.params.reference_image) {
        throw new Error('请选择参考图')
      }
      
      // 2. 更新状态
      view.status = 'creating'
      view.progress = 0
      view.error = null
      
      try {
        // 3. 调用API
        const response = await generateViewAPI(
          this.ipAsset.id, 
          viewKey, 
          view.params
        )
        
        // 4. 设置taskId
        view.taskId = response.task_id
        view.status = 'connecting'
        
        // 5. 创建WebSocket监听（如果还没有）
        if (!this.wsInstance) {
          this.wsInstance = useGenerationWebSocket()
          this.setupWebSocket()
        }
        
        // 6. 订阅任务进度
        this.wsInstance.subscribe(view.taskId, (data) => {
          this.handleProgressUpdate(viewKey, data)
        })
        
      } catch (error) {
        view.status = 'failed'
        view.error = error.message
        throw error
      }
    },
    
    /**
     * 处理进度更新
     */
    handleProgressUpdate(viewKey, data) {
      const view = this.views[viewKey]
      
      if (data.type === 'generation_progress') {
        view.status = 'generating'
        view.progress = data.data.progress
        view.message = data.data.message
      } 
      else if (data.type === 'generation_complete') {
        view.status = 'success'
        view.progress = 100
        view.result = data.data
        view.message = data.data.message
        
        // 取消订阅
        this.wsInstance.unsubscribe(view.taskId)
      }
      else if (data.type === 'generation_failed') {
        view.status = 'failed'
        view.progress = 0
        view.error = data.data.error
        view.message = data.data.message
        
        // 取消订阅
        this.wsInstance.unsubscribe(view.taskId)
      }
    },
    
    /**
     * 批量生成
     */
    async generateAll(strategy = 'sequential') {
      if (strategy === 'sequential') {
        await this.generateSequential()
      } else if (strategy === 'smart') {
        await this.generateSmart()
      } else if (strategy === 'parallel') {
        await this.generateParallel()
      }
    },
    
    /**
     * 依次生成
     */
    async generateSequential() {
      for (const viewKey of ['front', 'side', 'back']) {
        if (!this.canGenerate(viewKey)) continue
        
        try {
          await this.generateView(viewKey)
          await this.waitForCompletion(viewKey)
          
          if (this.views[viewKey].status === 'failed') {
            const shouldContinue = confirm('生成失败，是否继续？')
            if (!shouldContinue) break
          }
        } catch (error) {
          console.error(`Failed to generate ${viewKey}:`, error)
        }
      }
    },
    
    /**
     * 智能生成（先正面，成功后并行侧面+背面）
     */
    async generateSmart() {
      // 1. 生成正面
      await this.generateView('front')
      await this.waitForCompletion('front')
      
      if (this.views.front.status !== 'success') {
        return
      }
      
      // 2. 并行生成侧面和背面
      await Promise.all([
        this.generateView('side'),
        this.generateView('back')
      ])
    },
    
    /**
     * 等待完成
     */
    waitForCompletion(viewKey) {
      return new Promise((resolve) => {
        const unwatch = this.$subscribe((mutation, state) => {
          const status = state.views[viewKey].status
          if (status === 'success' || status === 'failed') {
            unwatch()
            resolve()
          }
        })
      })
    },
    
    /**
     * 重置视图
     */
    resetView(viewKey) {
      const view = this.views[viewKey]
      view.taskId = null
      view.status = 'pending'
      view.progress = 0
      view.result = null
      view.error = null
      view.message = null
    },
    
    /**
     * 重置全部
     */
    resetAll() {
      for (const viewKey of ['front', 'side', 'back']) {
        this.resetView(viewKey)
      }
    }
  }
})

function getDefaultParams() {
  return {
    reference_image: null,
    generation_mode: 'ip_adapter',
    ip_adapter_scale: 0.7,
    lora_weight: 0.7,
    use_lora: true,
    seed: -1,
    steps: 30,
    cfg_scale: 7.0,
    width: 512,
    height: 512,
    use_custom_prompt: false,
    custom_prompt: '',
  }
}
```

### 13.1 WebSocket连接池

```javascript
// 全局单例WebSocket
class WebSocketPool {
  constructor() {
    this.ws = null
    this.subscribers = new Map()
  }
  
  connect() {
    if (this.ws && this.ws.readyState === WebSocket.OPEN) {
      return
    }
    
    this.ws = new WebSocket(getWsUrl())
    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data)
      const handler = this.subscribers.get(data.task_id)
      if (handler) {
        handler(data)
      }
    }
  }
  
  subscribe(taskId, handler) {
    this.subscribers.set(taskId, handler)
  }
  
  unsubscribe(taskId) {
    this.subscribers.delete(taskId)
  }
}

// 全局实例
```

```python
def generate_optimization_suggestion(params, quality_score):
    """根据参数和质量评分给出优化建议"""
    suggestions = []
    
    if quality_score < 70:
        if params.get('ip_adapter_scale', 0) > 0.8:
            suggestions.append("IP-Adapter权重过高，建议降低到0.7")
        if params.get('lora_weight', 0) > 0.9:
            suggestions.append("LoRA权重过高，建议降低到0.7")
        if 'front view' not in params.get('prompt', ''):
            suggestions.append("Prompt缺少明确的视角关键词")
        if params.get('steps', 0) < 25:
            suggestions.append("采样步数过低，建议增加到30")
    
    return suggestions
```
