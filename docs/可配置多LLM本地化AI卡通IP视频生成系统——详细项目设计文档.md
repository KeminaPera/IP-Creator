# 可配置多LLM本地化AI卡通IP视频生成系统——详细项目设计文档

## 1\. 项目名称和背景

### 1\.1 项目全称

可配置多LLM本地化AI卡通IP视频生成系统（支持公私模型动态切换\+全链路IP短视频私有化生产平台）

### 1\.2 项目类型

AI工程化私有化部署项目、模块化中台型应用系统、端到端AIGC内容生产平台，适配本地GPU离线推理\+云端API混合双模运行架构，贴合短视频IP量产全业务链路开发落地。

### 1\.3 项目建设背景

当前AI卡通治愈系IP短视频（如水豚噜噜同款）量产需求爆发，现有商用平台存在三大核心痛点：一是公有平台数据强制上云，原创IP素材、创作脚本易泄露，无私有化数据保障；二是工具平台模型固化，无法自由搭配本地私有大模型、专属视频底模，算力成本高、合规风险大；三是IP形象一致性无法自主把控，无法闭环完成素材采集、专属LoRA训练、风格固化、批量视频生成全流程，长期量产同质化严重、版权无保障。

同时行业普遍存在混用AI模型刚需：私密剧情脚本、专属IP规划需本地离线大模型保障隐私，快速批量出片、日常轻量化创作可复用低成本公有云端LLM。市面暂无轻量化、可零代码配置、一键无感切换公私模型的一体化IP视频生产平台，因此亟需搭建一套自主可控、全链路解耦、适配本地部署的专属AI视频生产底座系统。

### 1\.4 核心解决问题（痛点闭环）

- **模型锁定痛点**：彻底摆脱第三方平台绑定，后台可视化配置，一键切换本地私有LLM / 公有云端LLM，全程无需改代码、无需重启服务、无需重构业务逻辑。

- **IP漂移痛点**：一站式闭环完成IP素材管理、标准化打标、专属LoRA私有化训练、形象锚定锁定、时空一致性视频生成，杜绝短视频角色脸型、配色、画风帧间跑偏闪烁。

- **数据安全痛点**：全链路支持离线本地闭环运行，原创IP原图、训练数据集、创作脚本、成品视频全程不上外网，核心资产自主可控不外泄。

- **成本效率痛点**：闲时用本地低成本GPU推理降本，忙时切云端弹性扩容提效，兼顾算力成本、出片速度、内容质量三重需求。

- **链路割裂痛点**：打通LLM文案分镜→IP图生成→LoRA专属微调→DiT架构视频生成→后期剪辑合成全链路，无需跨多平台跳转操作。

## 2\. 核心功能需求（全模块可落地，开发直接对标）

### 2\.1 核心能力总纲

系统以**可插拔LLM调度中台**为核心底座，以**私有化IP资产全生命周期管理**为业务主线，以**DiT\+扩散混合架构视频生成**为生产能力，完整实现：模型配置切换→IP素材治理→AI文案脚本→LoRA专属训练→文生图/图生图→文生短视频→后处理成片全流程自主可控生产。

### 2\.2 模块1：可视化多LLM配置与动态切换模块（系统核心底座）

核心定位：全系统最关键基础模块，统一屏蔽所有大模型接口差异，实现公私模型无感热切换。

- 模型台账可视化管理：支持批量录入、编辑、启用、停用、归档各类LLM资源，分类区分本地私有模型、云端商用模型。

- 双模式适配接入：本地模型兼容Ollama、本地Qwen、Llama、百川私有化部署底座；云端模型兼容智谱、字节混元、通义千问等标准OpenAI接口格式，全域通用适配。

- 零代码一键切换：后台下拉选择目标模型，秒级完成全局切换，历史任务不中断、前端页面无感知、业务流程不卡顿。

- 精细化参数全局配置：可视化预设模型温度值、随机性系数、上下文窗口大小、最大生成token数、超时响应阈值、并发调用上限；云端密钥、本地模型存储路径加密存储，全程不落地明文展示。

- 健康状态实时巡检：自动探测LLM连通性、推理延迟、显存占用、接口响应成功率，异常模型自动告警、自动熔断降级，保障业务不中断。

### 2\.3 模块2：全生命周期IP资产管控模块（IP量产核心资产库）

- 分级素材图库管理：支持IP正面、侧面、半身、全身、微动作多角度素材批量上传、智能分组、去重清洗、画质预检，自动过滤水印、模糊、多杂物料。

- 在线智能标签工作台：可视化编辑正向风格标签、结构特征标签、IP专属特征词、全局负面规避标签；自定义唯一专属触发词，后续一键唤醒专属IP形象。

- LoRA模型资产仓库：统一收纳本地训练/外部导入的\.safetensors标准格式LoRA文件，支持预览绑定IP、预设权重区间、快速挂载启用、过期模型归档清理。

- 行业风格模板预设：内置3D卡通、盲盒潮玩、治愈极简、暖黄柔光影、干净纯色背景等噜噜同款专属模板，一键套用无需手动编写基础提示词。

### 2\.4 模块3：轻量化私有化LoRA训练调度模块（原创IP自制核心）

- 傻瓜式任务创建面板：选择目标IP素材集、匹配对应图像底模/视频底模、填写专属触发词、可视化拖拽设置训练轮数、精细化学习率、批次大小等核心参数。

- 异步排队资源隔离：训练任务与视频生成任务智能错峰调度，自动划分GPU显存资源配额，避免高算力占用相互冲突卡顿。

- 全流程进度可视化：实时展示训练进度百分比、实时损失曲线、硬件显存占用日志、异常报错自动定位，新手也能全程监控。

- 训练完成自动入库：模型训练达标后自动合规校验、自动归档至LoRA资产库，可直接关联IP、一键挂载调用，无需手动迁移文件。

### 2\.5 模块4：AIGC全链路智能生成核心模块（业务生产核心）

- LLM赋能内容创作：调用当前已选中LLM，自动完成治愈系小故事编写、短视频分镜拆解、专业正向提示词优化、负面避雷词智能补充，降低创作门槛。

- 高一致性文生图/图生图：绑定专属LoRA\+IP\-Adapter参考图双约束，固定角色五官、体型、毛色、画风，批量产出无漂移、无崩坏的IP标准素材图。

- DiT主流架构视频生成：原生兼容当前主流SOTA视频架构，支持3D时空注意力建模，适配Seedance、CogVideo、Wan等商用级视频底模，输出高顺滑、高物理一致性短视频。

- 精细化视频参数可控：自由调节视频时长、分辨率、24标准帧率、采样迭代步数、CFG引导强度、LoRA挂载权重，适配不同使用场景画质需求。

### 2\.6 模块5：异步任务队列\+算力资源调度模块（系统稳定底座）

- 全类型任务统一托管：LoRA训练、图片生成、视频渲染、文案推理全部异步入队，后台自动排序调度，前端无需常驻等待。

- 显存智能弹性管控：限制单用户、单任务最大显存占用，自动规避显存溢出、程序闪退问题，适配6G及以上入门级消费显卡。

- 全量历史任务溯源：永久留存创作记录、模型参数、原始提示词、成品素材，支持一键复刻同款视频、二次微调迭代。

### 2\.7 模块6：轻量化视频智能后处理模块（直接出片闭环）

- 自动智能剪辑拼接：多段生成短视频无缝合成完整剧情成片，自动优化衔接帧，无卡顿断层。

- 配套轻量化包装：自动添加治愈系软字幕、舒缓背景配乐、统一柔和滤镜、标准化片头片尾，贴合IP短视频风格。

- 多格式合规导出：一键导出MP4通用短视频格式，适配抖音、快手、小红书全平台直接发布，无需二次转码。

### 2\.8 模块7：前台创作工作台\+后台运维管控模块

- 前台极简创作界面：零基础可视化操作，输入文案即可完成全流程创作，实时预览素材、视频效果，一键下载成品。

- 后台全权限运维面板：账号分级权限管控、模型资源运维、算力实时监控、操作日志全留存、异常行为溯源审计。

- 打通素材治理→标签打标→LoRA训练→DiT视频生成→后处理全链路私有化闭环，构建自主可控IP视频生产技术底座。

- 深度兼容2026主流AI视频架构：U\-Net轻量化架构、U\-Net\+Transformer混合架构、DiT全时空Transformer高阶架构，全场景适配覆盖。

- 适配入门级本地GPU硬件，最低6G显存即可稳定运行基础全功能，降低私有化部署硬件门槛。

- 封装轻量化私有部署SaaS工具包，面向中小自媒体创作者、个体工作室提供低成本IP定制视频赋能服务。

- 面向小微企业、品牌方提供私有化专属IP视频系统部署服务，保障品牌IP资产不外泄，自主量产宣传短视频。

- 完全脱离第三方AI平台限流、水印、版权约束，自有IP、自有素材、自有视频全版权自主持有，无合规纠纷。

## 5\. 硬性技术约束与非功能指标（开发必须严格遵守）

### 5\.1 强制技术栈约束

- 后端核心：Python为主工程化开发，采用插件化、模块化架构，适配AI推理全生态，易对接各类模型底座。

- AI推理依赖：原生兼容LangChain调度框架、Ollama本地模型中台、Kohya LoRA标准训练生态、Flux/SDXL图像底模、Seedance/CogVideo主流视频底模。

- 前端交互：Vue3轻量化后台管理\+创作工作台，界面简洁轻量化，低配电脑也能流畅运行。

- 数据存储：轻量MySQL/ SQLite本地数据库存储配置、任务、用户信息；本地文件目录闭环存储所有素材、模型、成品视频，不上云存储。

### 5\.2 性能硬性约束

- 硬件适配：最低兼容6G显存N卡本地运行全基础功能，推荐8G及以上显存，支持多任务轻度并发。

- 切换性能：LLM模型前后台切换响应时延≤2秒，服务无需重启、任务不中断、业务无感知。

- 任务稳定性：异步队列7×24小时稳定运行，训练、生成任务失败自动重试，无无故闪退、算力卡死问题。

- 出片效率：10秒标准治愈系IP短视频，中端显卡常规推理时长控制在3–8分钟内。

### 5\.3 安全与隐私合规约束

- 全链路离线可用：核心创作全流程支持断网本地运行，原创IP资产、核心数据全程不流出本地设备。

- 密钥加密存储：云端LLM接口密钥、私密配置全程加密入库，后台仅脱敏展示，禁止明文导出、复制。

- 权限分级隔离：普通用户仅可创作使用，管理员才可配置模型、管控算力、查看全量日志，严防资产误删、泄露。

- 操作全程留痕：所有模型调用、素材上传、训练操作、视频导出全日志留存，可溯源审计，符合商用合规要求。

### 5\.4 可扩展架构约束（长期迭代保障）

- 所有AI模型、业务功能均采用插件化接入，新增LLM、新增视频架构、新增风格模板，不动核心业务代码。

- 分层解耦强制规范：前端层、网关调度层、业务模块层、AI模型层、存储层完全解耦，可独立升级、单独运维。

- 接口统一标准化：所有内外调用统一Restful标准接口，后续对接小程序、APP、第三方后台无需二次改造。
