## 3. 核心设计

### 3.1 完整数据流设计

```
【阶段1: 前端提交】
用户填写参数 → 上传参考图（可选） → 点击"生成三视图"
  ↓
验证: currentIP存在? prompt长度≥10? 参考图有效?
  ↓

【阶段2: API请求】
POST /api/v1/ip/{ip_id}/generate-three-views
  ├─ 通用参数: ip_adapter_scale, lora_weight, steps, cfg_scale, width, height, seed, negative_prompt
  └─ views: [
       {
         view_type: "front",
         prompt: "...",
         reference_images: ["/path/to/front_ref.png"]  // 可选，最多1张
       },
       {
         view_type: "side",
         prompt: "...",
         reference_images: []  // 未上传，后端智能筛选
       },
       {
         view_type: "back",
         prompt: "...",
         reference_images: ["/path/to/back_ref.png"]  // 可选，最多1张
       }
     ]
  ↓

【阶段3: 后端处理 - ip_router.py】
1. 查询IP资产 (SELECT ip_assets WHERE id={ip_id})
2. 获取IP资产参考图（用于智能筛选降级）
3. 查询LoRA模型路径 (SELECT lora_models WHERE id={lora_model_id})
4. 验证views数组 (数量=3, view_type∈{front,side,back})
5. 创建3个Celery任务 (apply_async)
6. 创建3条task_records记录
7. 返回task_ids给前端
  ↓

【阶段4: Celery异步执行 - celery_worker.py】
每个视图独立执行:
  1. 调用 video_generator.generate_image(prompt, ip_asset_id, **kwargs)
     - kwargs包含: view_type, lora_path, reference_images, 等所有参数
     - ❌ view_type不传给generate_image (函数签名不支持)
  2. 保存图片到文件系统 (data/videos/images/ip_{id}/xxx.png)
  3. 创建generated_contents记录 (create_content_record)
  4. ✅ 创建ip_multi_views记录 (新增)
     - view_type从kwargs.get('view_type')提取
     - image_path从result.get('file_path')提取
     - generation_params保存所有参数(包含view_type，用于参数追溯)
  5. 更新task_records状态 (SUCCESS)
  ↓

【阶段5: 前端展示 - 多视图查询】
用户打开IP资产详情 → 查看多视图
  ↓
✅ 已有API: GET /api/v1/ip/{ip_id}/multi-views
  ↓
前端展示: 三张图片 (正面/侧面/背面)

说明:
- API已存在于 ip_feature_router.py (第85-102行)
- 前端已实现调用 (MultiViewManager.vue)
- 手动上传的视图可以正常查看
- AI生成的视图需要保存到ip_multi_views表后才能显示
```

#### **决策1: view_type传递路径**

#### **决策2: generation_params保存完整生成参数（包含view_type）**

**说明**: generation_params和表的独立字段作用不同，都需要保存view_type

```python

        "seed": kwargs.get('seed'),
        "steps": kwargs.get('steps', 30),
        "cfg_scale": kwargs.get('cfg_scale', 7.0),
        "ip_adapter_scale": kwargs.get('ip_adapter_scale', 0.85),
        "lora_weight": kwargs.get('lora_weight', 0.7),
        "lora_path": kwargs.get('lora_path'),
        "use_ip_adapter": kwargs.get('use_ip_adapter', False),
        "reference_images": kwargs.get('reference_images', []),
        "width": kwargs.get('width', 512),
        "height": kwargs.get('height', 512),
        "generation_time": execution_time,
    },
    quality_score=consistency_score,
    is_primary=(view_type == "front"),
)
```

**两个view_type的不同作用**:

| 字段 | 位置 | 作用 | 使用场景 |
|------|------|------|---------|
| **view_type** | IPMultiView表独立字段 | 数据库查询、排序、展示 | WHERE view_type='front'、ORDER BY view_type |
| **view_type** | generation_params JSON | 参数追溯、复现、调试 | 查看生成时使用了什么参数、重新生成 |

**为什么generation_params也需要view_type？**

1. ✅ **参数完整性**: 生成三视图时，view_type是重要参数，应该完整记录
2. ✅ **复现生成**: 用户可以查看generation_params，知道当时是用什么view_type生成的
3. ✅ **调试排查**: 如果生成的图片不对，可以检查generation_params中的view_type是否正确
4. ✅ **日志追溯**: 不依赖数据库表结构，仅从generation_params就能了解完整生成过程

## 4. API接口设计

### 4.1 Schema定义

```python
from pydantic import BaseModel, Field
from typing import Optional, List

class ViewConfig(BaseModel):
    """单个视图的配置"""
    view_type: str = Field(..., description="视图类型: front/side/back")
    prompt: str = Field(..., min_length=10, max_length=2000, description="正向提示词")
    reference_images: Optional[List[str]] = Field(
        default=None,
        description="参考图路径列表（可选，最多1张）",
        max_items=1
    )

class ThreeViewGenerationRequest(BaseModel):
    """三视图生成请求（支持参数分离）"""
    # 通用参数
    ip_adapter_scale: float = Field(default=0.85, ge=0.0, le=1.0)
    lora_weight: float = Field(default=0.7, ge=0.0, le=1.0)
    steps: int = Field(default=30, ge=10, le=100)
    cfg_scale: float = Field(default=7.0, ge=1.0, le=20.0)
    width: int = Field(default=512, ge=256, le=2048)
    height: int = Field(default=512, ge=256, le=2048)
    seed: Optional[int] = Field(default=None, ge=0, le=2**32-1, description="随机种子（可选）")
    negative_prompt: Optional[str] = Field(default=None, max_length=2000, description="负向提示词（共用）")
    
    # 独立参数（可选，不提供则使用默认提示词）
    views: Optional[List[ViewConfig]] = Field(
        default=None,
        description="三个视图的配置",
        min_items=0,
        max_items=3
    )
```

### 5.3 提交逻辑

```javascript
async function generateThreeViews() {
  if (!currentIP.value) {
    ElMessage.warning(t('ip.select_ip_first'))
    return
  }

  generating.value = true
  
  try {
    // 构建views数组并验证
    const views = viewTypes.map(view => {
      const prompt = viewConfigs.value[view.key]?.prompt?.trim() || view.defaultPrompt(currentIP.value)
      const refImages = viewConfigs.value[view.key]?.reference_images || []
      
      if (prompt.length < 10) {
        throw new Error(`${view.label}的提示词过短（至少10个字符）`)
      }
      
      // 验证参考图数量（最多1张）
      if (refImages.length > 1) {
        throw new Error(`${view.label}只能上传1张参考图`)
      }
      
      return {
        view_type: view.key,
        prompt: prompt,
        reference_images: refImages  // 用户上传的参考图（可能为空）
      }
    })
    
    // 组合请求数据
    const requestData = {
      ip_adapter_scale: sharedParams.value.ip_adapter_scale,
      lora_weight: sharedParams.value.lora_weight,
      steps: sharedParams.value.steps,
      cfg_scale: sharedParams.value.cfg_scale,
      width: sharedParams.value.resolution,
      height: sharedParams.value.resolution,
      seed: sharedParams.value.seed || undefined,
      negative_prompt: sharedParams.value.negative_prompt || currentIP.value.negative_prompt?.join(', '),
      views: views
    }
    
    const { data } = await request.post(
      `/ip/${currentIP.value.id}/generate-three-views`,
      requestData
    )
    
    if (!data.success) {
      throw new Error(data.message || t('common.generation_failed'))
    }
    
    ElMessage.success(t('ip.three_views_generated'))
    viewTaskIds.value = data.data.task_ids
    ElMessage.info(t('ip.check_tasks_for_progress'))
    
  } catch (err) {
    ElMessage.error(err.response?.data?.message || err.message || t('common.generation_failed'))
  } finally {
    generating.value = false
  }
}
```

## 6. 后端实现

### 6.1 ip_router.py

```python
from app.schemas.ip_schema import ThreeViewGenerationRequest, ViewConfig

@router.post("/{ip_id}/generate-three-views")
async def generate_three_views(
    ip_id: int,
    request: ThreeViewGenerationRequest = None,
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db_session),
):
    """生成三视图（支持参数分离）"""
    try:
        # 1. 查询IP资产
        result = await db.execute(select(IPAsset).where(IPAsset.id == ip_id))
        ip_asset = result.scalar_one_or_none()
        
        if not ip_asset:
            raise NotFoundException(message="IP asset not found")
        
        # 2. 检查LoRA模型
        lora_path = None
        if ip_asset.lora_model_id:
            lora_result = await db.execute(
                select(LoRAModel).where(LoRAModel.id == ip_asset.lora_model_id)
            )
            lora_model = lora_result.scalar_one_or_none()
            if lora_model and lora_model.status == 'completed':
                lora_path = lora_model.file_path
        
        # 3. 解析通用参数
        params = request.model_dump() if request else {}
        lora_weight = params.get("lora_weight", 0.7)
        ip_adapter_scale = params.get("ip_adapter_scale", 0.85)
        steps = params.get("steps", 30)
        cfg_scale = params.get("cfg_scale", 7.0)
        width = params.get("width", 512)
        height = params.get("height", 512)
        seed = params.get("seed")
        negative_prompt = params.get("negative_prompt") or ", ".join(ip_asset.negative_tags or ["ugly", "deformed", "text"])
        
        # 4. 验证并构建视图配置
        views_config = params.get("views")
        valid_view_types = {"front", "side", "back"}
        
        if views_config:
            # 验证数量
            if len(views_config) != 3:
                raise BadRequestException(message="必须提供3个视图的配置")
            
            # 验证view_type
            provided_types = {view["view_type"] for view in views_config}
            if provided_types != valid_view_types:
                invalid_types = provided_types - valid_view_types
                if invalid_types:
                    raise BadRequestException(message=f"无效的视图类型: {invalid_types}")
            
            # 使用前端传入的提示词和参考图
            views = {
                view["view_type"]: {
                    "prompt": view["prompt"],
                    "negative_prompt": negative_prompt,
                    "reference_images": view.get("reference_images", [])  # 用户上传的参考图
                }
                for view in views_config
            }
        else:
            # 使用默认提示词模板
            positive_tags_str = ", ".join(ip_asset.positive_tags or [])
            
            views = {
                "front": {
                    "prompt": f"{ip_asset.trigger_word}, front view, facing camera, full body, clean white background, masterpiece, best quality, {positive_tags_str}, {ip_asset.style_template or '3d_cartoon'} style",
                    "negative_prompt": negative_prompt,
                    "reference_images": []  # 未上传，使用智能筛选
                },
                "side": {
                    "prompt": f"{ip_asset.trigger_word}, side view, profile, 90 degrees, full body, clean white background, masterpiece, best quality, {positive_tags_str}, {ip_asset.style_template or '3d_cartoon'} style",
                    "negative_prompt": negative_prompt,
                    "reference_images": []
                },
                "back": {
                    "prompt": f"{ip_asset.trigger_word}, back view, from behind, full body, clean white background, masterpiece, best quality, {positive_tags_str}, {ip_asset.style_template or '3d_cartoon'} style",
                    "negative_prompt": negative_prompt,
                    "reference_images": []
                }
            }
        
        # 5. 处理参考图
        def select_reference_images(view_config, ip_asset, view_type, max_count=1):
            """
            选择参考图逻辑：
            1. 优先使用用户上传的参考图（如果有）
            2. 否则从IP资产参考图中智能筛选
            """
            # 情况1: 用户上传了参考图
            if view_config.get('reference_images'):
                user_refs = view_config['reference_images']
                if len(user_refs) > 0:
                    logger.info(f"Using user-uploaded reference images for view_type={view_type}: {user_refs}")
                    return user_refs[:1]  # 每个视图最多1张
            
            # 情况2: 从IP资产参考图中智能筛选
            reference_images = ip_asset.reference_images
            if not reference_images:
                logger.warning(f"No reference images available for view_type={view_type}")
                return []
            
            # 智能筛选逻辑（根据view_type匹配角度）
            angle_priority = {
                "front": ["front", "half_body", "full_body"],
                "side": ["side", "profile"],
                "back": ["back"]
            }
            
            priority_angles = angle_priority.get(view_type, [])
            selected = []
            
            for angle in priority_angles:
                matching = [img["path"] for img in reference_images if img.get("angle") == angle]
                selected.extend(matching)
                if len(selected) >= max_count:
                    break
            
            if not selected:
                logger.warning(f"No matching reference images for view_type={view_type}, using fallback")
                selected = [img["path"] for img in reference_images[:max_count]]
            
            logger.info(f"Smart selected {len(selected)} reference images for view_type={view_type}")
            return selected[:max_count]
        
        # 6. 创建任务
        task_ids = {}
        for view_name, view_data in views.items():
            # 处理参考图（用户上传优先，否则智能筛选）
            ref_images = select_reference_images(
                view_data,  # 包含reference_images字段
                ip_asset,
                view_name,
                max_count=1  # 每个视图最多1张参考图
            )
            
            # 构建kwargs（包含view_type，但video_generator会忽略它）
            task_kwargs = {
                "channel_id": None,
                "lora_path": lora_path,
                "lora_weight": lora_weight,
                "use_ip_adapter": True,
                "reference_images": ref_images,
                "negative_prompt": view_data["negative_prompt"],
                "ip_adapter_scale": ip_adapter_scale,
                "width": width,
                "height": height,
                "steps": steps,
                "cfg_scale": cfg_scale,
                "view_type": view_name,  # ← 传递给Celery任务
            }
            
            if seed is not None:
                task_kwargs["seed"] = seed
            
            task = generate_image_task.apply_async(
                args=[view_data["prompt"], ip_asset.id],
                kwargs=task_kwargs,
            )
            
            # 创建任务记录
            task_record = TaskRecord(
                task_id=task.id,
                task_type="image_generation",
                ip_asset_id=ip_asset.id,
                prompt=view_data["prompt"],
                parameters={
                    "view_type": view_name,
                    "lora_weight": lora_weight,
                    "ip_adapter_scale": ip_adapter_scale,
                    "width": width,
                    "height": height,
                    "steps": steps,
                    "cfg_scale": cfg_scale,
                },
                status="pending",
                created_by=current_user.get("id", 1),
                created_at=datetime.now(),
            )
            
            db.add(task_record)
            task_ids[view_name] = task.id
        
        await db.commit()
        
        return success_response(
            data={
                "task_ids": task_ids,
                "ip_id": ip_id,
                "ip_name": ip_asset.name,
            },
            message="三视图生成任务已创建"
        )
        
    except (NotFoundException, BadRequestException):
        raise
    except Exception as e:
        logger.error(f"Failed to create three views tasks for IP {ip_id}: {e}", exc_info=True)
        raise InternalServerError(message="Failed to create three views generation tasks")
```

```python
async def get_multi_views(
```

```python
@app.task(bind=True, max_retries=3)
def generate_image_task(self, prompt: str, ip_asset_id: int = 0, **kwargs):
    try:
        start_time = time.time()
        
        # ... 执行生成逻辑 ...
        
    except Exception as e:
        # 1. 记录详细错误信息
        error_message = f"Failed to generate image: {str(e)}\n"
        error_message += f"Task ID: {self.request.id}\n"
        error_message += f"IP Asset ID: {ip_asset_id}\n"
        error_message += f"View Type: {kwargs.get('view_type', 'unknown')}\n"
        error_message += f"Prompt: {prompt[:100]}...\n"
        error_message += f"Parameters: {kwargs}\n"
        error_message += f"Traceback: {traceback.format_exc()}"
        
        logger.error(error_message, exc_info=True)
        
        # 2. 更新task_records状态
        try:
            create_content_record(
                task_id=self.request.id,
                task_type='image_generation',
                content_type='image',
                result_data={
                    'status': 'failed',
                    'error': str(e),
                },
                execution_time=time.time() - start_time,
                error_message=error_message  # ← 保存到task_records
            )
        except Exception as db_error:
            logger.error(f"Failed to save error record: {db_error}")
        
        # 3. 抛出异常，Celery会标记任务为FAILED
        raise
```
